# Security control matrix (NIST SP 800-53 Rev. 5 families)

GovRAMP, FedRAMP, TX-RAMP and most state security questionnaires are organised around these
families. This matrix records, per family, what the product and company do today, where the
evidence is, and what is missing. It is a self-assessment for planning — **not an assessment
result**.

Status: **Built** (implemented with automated evidence) · **Partial** · **Planned** (designed,
not built) · **Hosting** (inherited from or implemented with the cloud platform, undecided) ·
**Org** (company policy/process, not software).

## Using this matrix

- When a customer sends a security questionnaire, answer from here and from SECURITY.md; never
  round a **Partial** up to "yes".
- When a control changes status, update this file in the same change as the code and cite the
  test or document that proves it.
- Before an assessment, this becomes the starting point for the System Security Plan; the
  assessor's findings replace the self-assessed statuses.
